A referência do Transparente é uma renderização 3D: a ficha dele explica o que o CSS consegue imitar e o que fica de fora (refração real).

## Regras

- **Só para consulta do time.** As imagens são de terceiros: não entram no pacote `@argila/ui`, no catálogo publicado, em exemplos, em ícones nem em testes.
- Copia-se a **linguagem visual** (forma, tipografia, organização, cores), nunca marcas, textos, fotos ou ilustrações.
- Os textos das imagens têm erros e trechos sem sentido (por exemplo, "Disable" no lugar de "Progress"). Vale o que a imagem **mostra**, e a ficha registra a interpretação.
- Trocar uma referência exige atualizar a ficha do DS no mesmo PR.
