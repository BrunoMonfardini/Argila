# Tokens

O Argila organiza os valores visuais em três camadas, do mais bruto ao mais específico:

| Camada     | Prefixo                | Exemplo               | Quem usa                                        |
| ---------- | ---------------------- | --------------------- | ----------------------------------------------- |
| Primitivos | `--arg-core-*`         | `--arg-core-clay-600` | Só a camada semântica                           |
| Semânticos | `--arg-*`              | `--arg-color-primary` | Componentes e produtos                          |
| Componente | `--arg-<componente>-*` | `--arg-button-bg`     | O próprio componente; ajuste fino por instância |

Um produto ou tenant muda a aparência sobrescrevendo **tokens semânticos** no `<html>`.
Use a barra de ferramentas (Tema, Marca) para ver claro/escuro e o tema de exemplo.

## Carregamento

Skeleton e spinner leem os tokens `--arg-loading-*`. Sobrescreva no `:root` para mudar o sistema inteiro:

| Token                            | Padrão                  | Controla                   |
| -------------------------------- | ----------------------- | -------------------------- |
| `--arg-loading-bg`               | cor do texto a 9%       | Fundo do skeleton          |
| `--arg-loading-highlight`        | cor da superfície a 55% | Faixa de brilho do shimmer |
| `--arg-loading-shimmer-duration` | 1400ms                  | Velocidade do shimmer      |
| `--arg-loading-spin-duration`    | 700ms                   | Velocidade do spinner      |

Uma instância ajusta só a si mesma com `--arg-skeleton-*` e `--arg-spinner-*`.

## Espaçamento

Base de 4px: `--arg-space-1` (4px), `-2` (8px), `-3` (12px), `-4` (16px), `-5` (20px),
`-6` (24px), `-8` (32px), `-10` (40px), `-12` (48px), `-16` (64px).

## Raio

Por papel, para que um tenant mude botões sem mexer em cards:
`--arg-radius-control` (botões, campos), `--arg-radius-container` (cards, modais), `--arg-radius-full`.
