# Argila

Biblioteca de componentes Angular compartilhada entre todos os nossos produtos. Cada página mostra o
componente funcionando, os controles para testar variações e o código para copiar.

Use a barra de ferramentas no topo para trocar o **Tema** (claro/escuro) e a **Marca** (padrão/exemplo):
todos os componentes acompanham, porque só usam tokens.
